# KaloNess — Manual QA Testing Project

## Project Overview
KaloNess is a health and fitness tracking application.

This repository documents my hands-on experience in manual software testing, API testing, and bug reporting.

## My Role
Manual QA Tester

## Testing Activities
- Created test scenarios and test cases.
- Performed functional and negative testing.
- Tested REST APIs using Postman.
- Verified stored data using Prisma Studio and SQLite.
- Investigated and documented software defects.
- Performed basic authentication and authorization checks.
